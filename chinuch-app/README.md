# ארכיון עיצובי Canva — בית חינוך חב"ד

מקום אחד ומוגן לכל העיצובים של בית החינוך: קישורי Canva וקבצים, מסודרים בקטגוריות
של חודשי השנה ושל אירועים מיוחדים, עם רצועת "רלוונטי עכשיו" שמחושבת לפי הלוח העברי.

## הפעלה (חד-פעמי)

1. **פרויקט Vercel** — מייבאים את הריפו הזה ל-Vercel (Framework Preset: *Other*).
2. **אחסון נתונים** — Storage → Create → **Upstash Redis**, ומחברים לפרויקט.
   משתני הסביבה `KV_REST_API_URL` ו-`KV_REST_API_TOKEN` מוזרקים אוטומטית.
3. **אחסון קבצים** — Storage → Create → **Blob**, ומחברים לפרויקט
   (`BLOB_READ_WRITE_TOKEN`). עד שזה קיים, העלאת קבצים מחזירה הודעה בעברית
   וקישורי Canva עובדים רגיל.
4. **מפתח ניהול** — Settings → Environment Variables → `ADMIN_KEY` = מחרוזת ארוכה
   ואקראית. זה המפתח שנותן גישה לפאנל הניהול.
5. נכנסים לאתר עם `ADMIN_KEY`, ובטאב הניהול מגדירים את בתי הספר. **כל בית ספר
   מקבל מפתח משלו** — אותו שולחים למורות שלו.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html`, `styles.css`, `app.js` | כל הממשק. בלי framework ובלי build |
| `api/auth.mjs` | כניסה עם מפתח, עוגייה של 30 יום, יציאה |
| `api/items.mjs` | הפריטים, ההרשאות, ורצועת "רלוונטי עכשיו" |
| `api/config.mjs` | בתי ספר וקטגוריות (ניהול בלבד) |
| `api/file.mjs` | הורדת קובץ ותמונת תצוגה, מאחורי בדיקת הרשאה |
| `api/upload.mjs` | חתימת העלאה ישירה ל-Vercel Blob |
| `api/_hebrew.mjs` | הלוח העברי: המרת תאריכים, חגים, חלונות רלוונטיות |
| `api/_guard.mjs` | זיהוי, תפקידים, הגבלת קצב |
| `api/_store.mjs` | מתאם KV מול Upstash |
| `api/_seed.mjs` | הקטגוריות שהמערכת עולה איתן |
| `tests/api.test.mjs` | בדיקת קצה-לקצה מול Upstash מדומה בזיכרון |
| `docs/spec.md` | האיפיון המלא, כולל מה שעוד לא נבנה |

## בדיקות

```bash
node tests/api.test.mjs
```

43 בדיקות שעוברות על הרשאות, יצירה, סינון לפי בית ספר, הרלוונטיות, מחיקה ושחזור.
הן לא דורשות Upstash אמיתי — הבדיקה מקימה שרת תואם בזיכרון.

## מה עוד לא נבנה

חשבונות אישיות למורות (כניסה בקוד חד-פעמי למייל ואישור של מנהלת בית הספר) הם
השלב הבא. עד אז הזהות היא מפתח בית הספר, וההפרדה בין בתי הספר נאכפת בשרת לפיו.
הפירוט המלא ב-`docs/spec.md`.
